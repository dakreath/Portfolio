# Dak Ngueny: Portfolio

My personal portfolio website, built with React, Vite, Tailwind CSS and Framer Motion.

Live: https://dakreath.github.io/Portfolio/

## Run it

```bash
npm install      # first time only
npm run dev      # open http://localhost:5173
npm run deploy   # publish to GitHub Pages
```

## Change the content

All the text and links are in `src/data/`:

- `site.js`: name, email, social links, resume
- `hero.js`: top of the page
- `about.js`: about me and fun facts
- `journey.js`: timeline
- `projects.js`: projects
- `skills.js`: skills

## Contact form

Copy `.env.example` to `.env` and add a free key from [web3forms.com](https://web3forms.com).
